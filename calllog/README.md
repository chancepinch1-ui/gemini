# 📞 통화기록 통합관리 시스템

직원들의 **통화기록(고객명·전화번호·통화내용·녹음)**을 한 곳에 모아, **관리자가 한 화면에서**
조회·검색·필터링하고 통계를 확인하며 **녹음을 바로 재생**할 수 있는 시스템입니다.

외부 라이브러리 설치 없이 **Python 표준 라이브러리만으로** 동작합니다
(`sqlite3` 저장 + `http.server` 웹).

## 수집 방식

| 플랫폼 | 방식 |
|--------|------|
| **안드로이드** | OS 기본 전화앱이 저장한 **통화녹음 파일을 앱이 자동 업로드** (번호·시각·통화시간 메타 포함). 가이드: [`ANDROID.md`](ANDROID.md) |
| **아이폰** | iOS는 통화녹음·통화기록 접근이 OS 차원에서 불가 → 웹 **"통화 입력"** 탭으로 수동 입력 |

> ⚖️ 통화 녹음·수집은 당사자 동의, 근로자 고지 등 법적 검토가 필요합니다.

## 실행

```bash
python -m calllog                                   # http://127.0.0.1:8770
# 사내망 공유 + 업로드 인증키
CALLLOG_HOST=0.0.0.0 CALLLOG_API_KEY=secret123 python -m calllog
```

## 화면

| 탭 | 대상 | 기능 |
|----|------|------|
| **통화 입력** | 직원(아이폰 등) | 직원명·고객명·전화번호·통화내용·분류·통화방향·일시 입력 |
| **관리자 조회** | 관리자 | 전체/오늘/녹음보유 통계, 직원별 건수, 직원·분류·검색어 필터, **녹음 재생**, 삭제 |

- **분류**: 문의 / 상담 / 불만 / 계약 / AS / 기타
- **통화방향**: 수신 / 발신 / 부재중 / 기타
- **검색**: 고객명·전화번호·통화내용·직원명 부분 일치

## 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `CALLLOG_HOST` | `127.0.0.1` | 바인딩 호스트 (`0.0.0.0`이면 외부 접속 허용) |
| `CALLLOG_PORT` | `8770` | 포트 |
| `CALLLOG_DB` | `calllog.db` | SQLite 데이터베이스 파일 경로 |
| `CALLLOG_RECORDINGS` | `recordings` | 녹음 파일 저장 디렉터리 |
| `CALLLOG_API_KEY` | (없음) | 설정 시 업로드 API에 `X-Api-Key` 헤더 필수 |

## 구조

```
calllog/
├── __main__.py   # 진입점 (python -m calllog)
├── config.py     # 환경 변수 설정
├── models.py     # CallLog 모델 / 분류·방향 목록
├── db.py         # SQLite 저장 계층 (등록/조회/삭제/통계 + 녹음파일 + 마이그레이션)
├── web.py        # 웹 UI + JSON API + 업로드/재생
├── ANDROID.md    # 안드로이드 자동 업로드 연동 가이드
examples/
└── upload_recording.py   # 녹음 업로드 예제 스크립트
```

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/api/meta` | 분류·방향 목록, 직원 목록, 통계 |
| `GET` | `/api/logs?employee=&category=&q=` | 통화기록 목록(필터) |
| `GET` | `/api/recording/<id>` | 해당 기록의 녹음 파일 스트리밍(재생) |
| `POST` | `/api/logs` | 통화기록 수동 등록(JSON) |
| `POST` | `/api/logs/upload?...` | 녹음 + 메타데이터 업로드 (본문=오디오 raw, `X-Api-Key`) |
| `POST` | `/api/logs/delete` | 통화기록 삭제 (`{"id": N}`, 녹음 파일도 함께 삭제) |

# 📞 통화기록 통합관리 시스템

직원들이 각자의 **통화내용·고객명·전화번호**를 입력하면, **관리자가 한 화면에서**
모든 직원의 기록을 조회·검색·필터링하고 통계를 확인할 수 있는 시스템입니다.

외부 라이브러리 설치 없이 **Python 표준 라이브러리만으로** 동작합니다
(`sqlite3` 저장 + `http.server` 웹).

## 실행

```bash
python -m calllog
```

기본적으로 <http://127.0.0.1:8770> 에서 열립니다.

## 화면

| 탭 | 대상 | 기능 |
|----|------|------|
| **통화 입력** | 직원 | 직원명·고객명·전화번호·통화내용·분류·통화일시 입력 후 저장 |
| **관리자 조회** | 관리자 | 전체 통계, 직원별 건수, 직원/분류/검색어 필터, 기록 삭제 |

- **분류**: 문의 / 상담 / 불만 / 계약 / AS / 기타
- **검색**: 고객명·전화번호·통화내용·직원명 부분 일치 검색

## 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `CALLLOG_HOST` | `127.0.0.1` | 바인딩 호스트 |
| `CALLLOG_PORT` | `8770` | 포트 |
| `CALLLOG_DB` | `calllog.db` | SQLite 데이터베이스 파일 경로 |

예) 사내 네트워크에서 다른 직원 PC가 접속하게 하려면:

```bash
CALLLOG_HOST=0.0.0.0 CALLLOG_PORT=8770 python -m calllog
```

## 구조

```
calllog/
├── __main__.py   # 진입점 (python -m calllog)
├── config.py     # 환경 변수 설정
├── models.py     # CallLog 데이터 모델 / 분류 목록
├── db.py         # SQLite 저장 계층 (등록/조회/삭제/통계)
└── web.py        # 웹 UI + JSON API
```

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/api/meta` | 분류 목록, 직원 목록, 통계 |
| `GET` | `/api/logs?employee=&category=&q=` | 통화기록 목록(필터) |
| `POST` | `/api/logs` | 통화기록 등록 |
| `POST` | `/api/logs/delete` | 통화기록 삭제 (`{"id": N}`) |
